# YoYo桥 部署方法（v2，2026-11-22）

## 这是什么

YoYo桥是一个 Muse Space（显示名「YoYo桥」，slug `yoyo-bridge`）：本地画布经 Cloudflare 隧道把生成任务交给这里执行，结果再回送本地。桥本身只做四件事：领取任务、派发执行、回送结果、清理台账。

本包是 2026-11-22 当天线上版本的完整源码快照，已包含以下修复与改动（部署时不要回退）：

1. **queued 孤儿对账**：全量同步轮内新增对账（`reconcileOrphanedQueued`）——本地停止/取消的任务自动结算，不再永久冻结在「待处理」。
2. **终态显示「已完成」**：内部 status 仍为 `cleaned`，页面计数与最近任务标签显示「已完成」。
3. **清除配对二次确认**：点「清除配对」先弹窗，必须手动输入 `yes` 才可执行。
4. **页面 5 秒自动轮询**：状态查询 `refetchInterval: 5000`，与同步节奏对齐；标签页切到后台时自动暂停。
5. **清除失败记录自助入口**：设置页显示可清除条数，二次确认后可删失败记录。
6. **生成通道永久锁定**：只走 Muse 内置生成管线，永久禁用 MiniMax Token Plan（见红线）。

## 部署步骤

1. **建 Space**：按包内源码原样创建 Space，slug 必须是 `yoyo-bridge`，显示名「YoYo桥」。源码逐文件落入，不要改任何行为口径；`icon.webp` 若被运行时托管图标替代属正常例外。
2. **跑迁移**：迁移 0001 + 0002 自动执行，建 `bridge_config`（1 行）与 `bridge_jobs`（0 行）两表。
3. **建两个定时任务**（owner 均为 `space:yoyo-bridge`，均以 space_action 直调，静默运行）：
   - `yoyo-bridge-sync`：每 **5 秒**直调 `bridgeSync`（全量轮：领取新任务 + 对账 + 跟进）
   - `yoyo-bridge-fast`：每 **5 秒**直调 `bridgeFastSync`（快速轮：只跟进在途任务的回送与清理，不领新任务）
4. **批准网络放行**：两个定时任务首次访问隧道域名时各会弹一次网络批准（目标为配对的隧道域名 `:443`），Sync 与 Fast 各批一次，均选**始终允许**。不批则对应轮次无法出网，表现为空转或报错。
5. **配对**（见下节分工），配对后做验收（见验收清单）。

## 配对分工（重要）

配对需要两样只能由用户提供的信息，部署方（Muse）不能代填、不能猜：

| 信息 | 从哪来 | 怎么用 |
| --- | --- | --- |
| 隧道地址 | 用户本地画布经 Cloudflare 隧道暴露的 https 地址，形态如 `https://yoyo-bridge.example.com` | 填入 YoYo桥设置页的配对表单 |
| 桥令牌 | 用户在本机打开 `http://127.0.0.1:3737/bridge-admin`，在本地桥管理页新建档案后获得 | 只许填入设置页配对表单；页面回显只显示掩码 |

**令牌红线**：桥令牌严禁写入任何代码、文档、日志、记忆或聊天回报（回报只许提掩码）。本包所有文档中出现的地址均为占位示例，不是真实地址。

## 验收清单

- [ ] 设置页可打开，显示未配对、各状态计数为 0、无错误
- [ ] 实调 `bridgeStatus` 返回正常（configured=false、计数全 0）
- [ ] 两个定时任务已启用，查真实触发记录：sync 与 fast 均按 5 秒间隔连续成功触发
- [ ] 未配对时两轮同步均成功空转（回 `skipped` / `not_configured`），不报错
- [ ] 配对完成后设置页显示「已配对」、令牌为掩码、「本地最后在线」有时间、错误栏为空
- [ ] 终验一单：本地画布把该档案设为当前，发起一单 **16:9 纯提示词生图**，任务经桥领取→执行→回送，结果自动落回本地节点；全程约 1 分钟量级（实测干净一单 1152×2048 约 58 秒）
- [ ] 页面开着不刷新，计数与最近任务能随 5 秒轮询自行更新

## 红线

- **永久禁用 MiniMax Token Plan**：桥与画布的生成派发只走 Muse 内置管线；内置不可用就直接失败回送，绝不许用 MiniMax 或任何消耗用户订阅额度的外部通道兜底。task-image / task-video / task-audio 的派发报文内已写死此禁令，不要删改。
- 桥令牌只进设置页表单，不落盘、不进文档/代码/日志。
- 清除配对是破坏性操作，页面已设「输入 yes」确认，不要绕过。
- 同步间隔已定版为两条都 5 秒（用户 2026-11-22 点选固定 5 秒，否决自适应调速），改间隔须用户点头。

## 故障速查（部署/配对阶段）

| 现象 | 含义 | 处理 |
| --- | --- | --- |
| `/bridge/pending` 返回 530、正文 error code 1033 | Cloudflare 隧道离线，无连接器在线 | 本机启动 cloudflared 命名隧道，确认其绑定的是配对域名那条隧道 |
| 返回 502 | 隧道通了但本地源站异常 | 查本机本地桥服务（127.0.0.1:3737）是否在跑、是否报错 |
| `ECONNRESET` | 连接被本地侧关闭 | 查本地桥处理日志：带令牌的请求（取参考文件 / ack-claim）在本地执行时断开 |
| 无令牌请求返回 401 `invalid_bridge_token` | 正常鉴权 | 不是故障，说明隧道与本地服务都活着 |
| 参考文件下载 404 | 本地中继文件缺失，或路径出现双斜杠 | 查本地项目 `_bridge` 目录中继文件是否在盘上 |
| 本地停掉的任务在桥里显示待处理 | 已由对账机制自动处理 | 等一轮全量同步 + 60 秒宽限，行会被自动结算为失败并走到已完成（清理） |
