你现在要部署「YoYo桥」Space。本提示词自包含：按步骤执行，全部验收通过才算完成，中途不要改任何源码行为口径。

## 背景

YoYo桥：本地画布经 Cloudflare 隧道把生成任务交给云端 Space 执行，结果再回送本地。本压缩包是完整源码快照（client / server / drizzle 齐全），已包含孤儿对账、终态显示「已完成」、清除配对 yes 确认、页面 5 秒轮询、清除失败记录入口、生成通道锁定等全部现行改动，原样部署，不要回退、不要「优化」。

## 步骤

1. **建 Space**：用包内源码原样创建 Space，slug 必须为 `yoyo-bridge`，显示名「YoYo桥」。建完逐文件核对包内文件与 Space 内文件一致（`icon.webp` 被运行时托管图标替代属唯一正常例外）。
2. **确认迁移**：迁移 0001 + 0002 应自动建好 `bridge_config`（1 行）与 `bridge_jobs`（0 行）两表；六个动作齐备：bridgeSync、bridgeFastSync、bridgeSetConfig、bridgeStatus、completeBridgeJob、failBridgeJob（外加 bridgeClearFailed）。
3. **建两个定时任务**（owner 均为 `space:yoyo-bridge`，execution 为 space_action 直调，静默运行）：
   - `yoyo-bridge-sync`：每 5 秒直调 `bridgeSync`
   - `yoyo-bridge-fast`：每 5 秒直调 `bridgeFastSync`
   建完查真实触发记录确认两条都在按 5 秒连续成功触发，不是只看定义。
4. **等用户配对**：配对需要两样只能由用户提供的信息，你不能代填、不能猜、不能索要明文记录：
   - 隧道地址：用户本地画布经 Cloudflare 隧道暴露的 https 地址（形态如 `https://yoyo-bridge.example.com`，文档里的都是占位示例，不是真地址）
   - 桥令牌：请用户在本机打开 `http://127.0.0.1:3737/bridge-admin`，在本地桥管理页新建档案获得，然后由用户（或你经设置页表单）在 YoYo桥设置页填入隧道地址与令牌完成配对。
5. **批准放行**：配对后两个定时任务首次访问隧道域名（:443）时各弹一次网络批准，Sync 与 Fast 各批一次，均选始终允许。
6. **验收**（逐项实测，不要凭定义推断）：
   - 设置页可打开；未配对时 `bridgeStatus` 正常、各计数为 0、无错误
   - 未配对时两轮同步成功空转（`skipped` / `not_configured`），不报错
   - 配对后设置页显示已配对、令牌掩码、「本地最后在线」有时间、错误栏为空
   - 请用户在本地把该档案设为当前，发起一单 16:9 纯提示词生图：任务要经桥领取→执行→回送，结果自动落回本地节点，全程约 1 分钟量级（实测 1152×2048 干净一单约 58 秒）
   - 页面开着不刷新，计数与最近任务随 5 秒轮询自行更新

## 红线（不可违反）

- **桥令牌只许填设置页配对表单**：严禁写入代码、文档、日志、记忆文件；向用户回报时只许提掩码形式（只露头尾各几位、中间打码的那种页面回显），不许出现完整令牌。
- **永久禁用 MiniMax Token Plan**：生成派发锁死 Muse 内置管线；内置不可用就直接失败，不许接、不许重建、不许用 MiniMax 或任何消耗用户订阅额度的外部通道兜底。源码报文里的禁令原文不要删改。
- 同步间隔固定两条都 5 秒，不要自作主张改间隔、不要加自适应调速器。
- 清除配对必须走页面弹窗并手动输入 `yes`，不要通过直接调动作绕过确认去清配对。
- 不要动用户其他 Space、定时任务与本地文件；本任务范围只有 YoYo桥。

## 故障速查

- 530 / error code 1033 = 隧道离线（cloudflared 没连上），查本机命名隧道，不是桥的错。
- 502 = 隧道通、本地源站异常，查本机 127.0.0.1:3737 的本地桥服务。
- ECONNRESET = 连接被本地侧关闭，查本地桥处理日志。
- 无令牌打 `/bridge/pending` 回 401 是正常鉴权，说明链路活着。
- 参考文件下载 404 = 本地中继文件缺失或路径双斜杠，查本地项目 `_bridge` 目录。
- 本地停止的任务在桥里短暂显示待处理是正常现象：对账会在一轮全量同步 + 60 秒宽限后自动结算，不要手动干预，更不要改对账逻辑。
